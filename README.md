\# Rice Disease Detection



AI-based rice disease detection using YOLO11s.



\## Model



\- Model: YOLO11s

\- Framework: Ultralytics

\- Input size: 640x640

\- Classes: 4



\## Classes



\- Bacterial Leaf Blight

\- Brown Spot

\- Healthy

\- Rice Blast



\## Model File



The trained production model is available at:



`models/rice\_disease\_yolo11s.pt`



\## Intended Use



This model performs AI-based screening of rice leaf images for visible disease symptoms.



\## Important



The prediction is intended as decision support and should not replace confirmation from an agricultural expert.
